### CLIP 토큰 최적 순서

모든 프롬프트를 다음 순서로 재구성:


## 장점 및 효과

### 1. SD 처리 순서 최적화
- CLIP 토큰이 앞에서부터 순차적으로 처리됨
- 중요한 요소(자세, 체위)가 먼저 처리되어 더 안정적인 생성

### 2. 영문 자연어 순서 일치
```
She is lying on bed with legs spread in missionary position from side view...
```
- 자연스러운 영문 서술 구조와 일치
- SD가 프롬프트를 더 잘 이해

### 3. 일관성 및 유지보수성
- 모든 포즈가 동일한 구조 패턴을 따름
- 검열, 노출, 체액 태그가 표준화됨
- 새 포즈 추가 시 일관된 형식 유지 용이

### 4. 콘솔 출력 가독성 유지
- 첫 2-3개 단어만 봐도 무슨 포즈인지 파악 가능
- 예: "lying on bed, legs spread..." → 정상위 계열
- 예: "straddling seated, cowgirl..." → 기승위 계열
- 인위적인 라벨 불필요
