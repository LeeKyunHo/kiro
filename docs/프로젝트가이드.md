## 프로젝트 구성 요소

### 1. 프로젝트 폴더

#### 명명 규칙
- 소문자 영문 약어 권장
- 3-4자 권장 (예: `fth`, `oto`, `sfk`)
- 공백 없음, 언더스코어 허용

#### 생성 방법
```bash
mkdir projects\프로젝트명
mkdir projects\프로젝트명\characters
mkdir projects\프로젝트명\assets
```

### 3. 에셋 폴더

#### 자동 생성
스크립트 실행 시 자동으로 생성됨:
`projects\[프로젝트명]\assets\[캐릭터명]\`

#### 파일명 규칙
`[캐릭터명]_[포즈번호].webp`
- 포즈번호: 3자리 (001, 052, 140)
- 형식: WebP
- 품질: 95

#### 생성 해상도
- **832×1216 고정** (SDXL/Illustrious/NoobAI 네이티브)
- 권장 체크포인트: **LuminarQMix v7.1 e-Pred**
  - NoobAIXL + Illustrious 병합 모델
  - e-Pred 방식: 표준 샘플러 완벽 호환
  - Danbooru 태그 해석력 최대화

## 프로젝트 작업 흐름

### 신규 프로젝트 생성

1. **프로젝트 폴더 구조 생성**
```bash
mkdir projects\프로젝트명
mkdir projects\프로젝트명\characters
mkdir projects\프로젝트명\assets
```

2. **첫 캐릭터 JSON 작성**
템플릿을 복사하여 수정하거나 처음부터 작성

3. **테스트 생성**
```bash
python sd_batch_generator.py --character 프로젝트명\캐릭터명 --mode emotions --range 0-5
```

4. **검증 및 조정**
생성된 이미지 확인 후 JSON 프롬프트 조정

5. **전체 생성**
감정 → 포즈 → H씬 순으로 전체 생성

### 캐릭터 추가

1. **새 캐릭터 JSON 생성**
`projects\프로젝트명\characters\새캐릭터.json`

2. **동일 프로세스 반복**
테스트 → 조정 → 전체 생성

### 프로젝트 유지보수

#### 캐릭터 재생성
- 특정 이미지만: `--range 번호-번호`
- 전체: 배치 파일 사용

#### 프롬프트 조정
- JSON 수정 후 재생성
- 일부 이미지만 재생성 가능

## 배치 파일 관리

### 프로젝트 루트 배치 파일

**전체 재생성 (run_all.bat):**
```batch
@echo off
echo Generating all characters...

call run_val.bat
call run_mik.bat
call run_rox.bat

echo All projects completed!
pause
```

**특정 포즈만 (run_006.bat):**
```batch
@echo off
python sd_batch_generator.py --character dark_generals\bel --mode emotions --range 6-6
python sd_batch_generator.py --character dark_generals\cam --mode emotions --range 6-6
REM 다른 캐릭터들...
pause
```

### 캐릭터별 배치 파일

**run_캐릭터명.bat:**
```batch
@echo off
set CHARACTER=프로젝트\캐릭터

echo [1/4] Generating emotions...
python sd_batch_generator.py --character %CHARACTER% --mode emotions --range 0-20

echo [2/4] Generating poses...
python sd_batch_generator.py --character %CHARACTER% --mode poses --range 21-37

echo [3/4] Generating h_scenes...
python sd_batch_generator.py --character %CHARACTER% --mode h_scenes --range 40-75

echo [4/4] Generating scenes_otokonoko...
python sd_batch_generator.py --character %CHARACTER% --mode scenes_otokonoko --range 140-170

echo Complete!
pause
```
