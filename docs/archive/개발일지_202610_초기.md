- **NiceGUI 부모 슬롯 삭제(Deleted Slot) 런타임 크래시 방어**:
  - **원인 분석**: 퀵 버튼 클릭 핸들러에서 `update_control_bars()`로 버튼이 속한 부모 컨테이너(`matrix_controls.clear()`)를 먼저 비운 뒤 `ui.notify()`를 호출하면서, NiceGUI가 이미 파괴된 슬롯의 클라이언트를 조회하지 못해 `RuntimeError: The parent element this slot belongs to has been deleted.`를 던지며 이벤트가 끊어짐.
  - **해결 조치**: 슬롯이 유지된 상태인 `update_control_bars()` 호출 직전에 `ui.notify()`를 선행 실행하고 `try...except` 안전 래퍼를 씌워 이벤트 루프의 안정성을 100% 확보함.
