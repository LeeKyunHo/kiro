# SD 배치 이미지 생성기 사용법

## 개요
이 시스템은 Stable Diffusion WebUI Forge를 활용하여 챗봇 캐릭터용 이미지 에셋을 자동으로 생성합니다.

## 사전 요구사항

### 하드웨어
- GPU: NVIDIA RTX 4060 Ti (8GB VRAM)
- RAM: 48GB
- CPU: Intel i5-13600KF

### 소프트웨어
- Python 3.10 이상 (3.14 미만)
- Stable Diffusion WebUI Forge
- 필요한 Python 패키지: requests

## 설치 및 설정

### 1. SD WebUI Forge 설치
```bash
git clone https://github.com/lllyasviel/stable-diffusion-webui-forge.git
cd stable-diffusion-webui-forge
```

### 2. WebUI 실행 설정
`webui-user.bat` 파일을 수정하여 다음 플래그만 설정:
```
set COMMANDLINE_ARGS=--api
```

**주의**: Forge는 최적화를 자동으로 관리하므로 추가 최적화 플래그는 필요하지 않습니다.

### 3. WebUI 실행
```bash
webui-user.bat
```

기본적으로 `http://localhost:7860`에서 실행됩니다.

## 사용 방법

### 1. 캐릭터 JSON 준비
프로젝트 폴더에 캐릭터 JSON 파일을 생성합니다:

**폴더 구조:**
```
c:\Users\rbsgh\kiro\projects\
└── [프로젝트명]\
    └── characters\
        └── [캐릭터명].json
```

**캐릭터 JSON 예시:**
```json
{
  "name": "캐릭터명",
  "checkpoint": "모델명.safetensors",
  "vae": "vae명.safetensors",
  "positive_prompt": "1girl, long hair, blue eyes, ...",
  "negative_prompt": "worst quality, low quality, ..."
}
```

### 2. 배치 생성 실행

#### 방법 A: Python 직접 실행
```bash
python sd_batch_generator.py --character 프로젝트명\캐릭터명 --mode emotions --range 0-20
```

#### 방법 B: 배치 파일 실행
프로젝트 폴더에 `.bat` 파일을 생성:
```batch
@echo off
python c:\Users\rbsgh\kiro\sd_batch_generator.py --character 프로젝트명\캐릭터명 --mode emotions --range 0-20
pause
```

### 3. 명령줄 옵션

- `--character`: 프로젝트명\캐릭터명 형식 (필수)
- `--mode`: 포즈 섹션 (emotions, poses, h_scenes, scenes_otokonoko)
- `--range`: 생성할 포즈 범위 (예: 0-20, 40-75, 140-170)

**예시:**
```bash
# 감정 표현 생성 (0-20)
python sd_batch_generator.py --character fth\val --mode emotions --range 0-20

# 일반 포즈 생성 (21-37)
python sd_batch_generator.py --character fth\val --mode poses --range 21-37

# H씬 생성 (여성, 40-75)
python sd_batch_generator.py --character fth\val --mode h_scenes --range 40-75

# H씬 생성 (오토코노코, 140-170)
python sd_batch_generator.py --character oto\mik --mode scenes_otokonoko --range 140-170
```

### 4. 출력 결과
생성된 이미지는 다음 경로에 저장됩니다:
```
c:\Users\rbsgh\kiro\projects\[프로젝트명]\assets\[캐릭터명]\
```

파일명 형식: `[캐릭터명]_[포즈번호].webp`  
예: `val_001.webp`, `mik_140.webp`

## 문제 해결

### Python 실행 안됨
Windows의 App Execution Alias가 실제 Python을 차단할 수 있습니다.

**해결 방법:**
1. Windows 설정 → 앱 → 앱 실행 별칭
2. python.exe 및 python3.exe 비활성화
3. 터미널 재시작

### WebUI 연결 실패
1. SD WebUI가 실행 중인지 확인
2. `http://localhost:7860`에 접속 가능한지 확인
3. `--api` 플래그가 설정되어 있는지 확인

### 검열 스타일 변경
모든 포즈에서 무광 검정 페인트/고무 스타일 검열이 적용됩니다.
- 모자이크나 바 형태가 아닌 솔리드한 무광 검정색
- 가슴은 검열되지 않음

### 동물귀 오염 문제
모든 캐릭터 JSON negative_prompt에 다음 태그 추가:
```
animal ears, cat ears, beast ears, fox ears, dog ears, animal tail
```

## 팁과 권장사항

1. **단계별 생성**: 감정 → 포즈 → H씬 순서로 생성
2. **결과 확인**: 각 단계 후 이미지 품질 확인
3. **재생성**: 문제가 있는 이미지는 개별 번호만 지정하여 재생성
4. **배치 파일 활용**: 자주 사용하는 명령은 `.bat` 파일로 저장
