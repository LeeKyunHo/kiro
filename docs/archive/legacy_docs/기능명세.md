# SD 배치 이미지 생성기 기능명세

## 시스템 개요

### 목적
Stable Diffusion WebUI Forge API를 통해 챗봇 캐릭터용 이미지 에셋을 자동 배치 생성

### 핵심 기능
1. 캐릭터별 프롬프트 관리
2. 포즈 데이터베이스 기반 자동 생성
3. 배치 처리 및 에러 복구
4. WebP 형식으로 최적화된 출력

## 핵심 컴포넌트

### 1. sd_batch_generator.py

#### 주요 함수

**load_character_config(character_name)**
- 캐릭터 JSON 파일 로드
- 필수 필드 검증 (name, checkpoint, vae, positive_prompt, negative_prompt)
- 반환: 캐릭터 설정 딕셔너리

**load_pose_database()**
- pose_database.json 로드
- 섹션별 포즈 프롬프트 파싱
- 반환: 포즈 데이터베이스 딕셔너리

**generate_image(payload)**
- SD WebUI Forge API 호출 (/sdapi/v1/txt2img)
- 응답 처리 및 base64 디코딩
- 에러 핸들링 및 재시도 로직
- 반환: 디코딩된 이미지 데이터

**save_image(image_data, output_path)**
- WebP 형식으로 이미지 저장
- 품질 설정 적용 (현재 95)
- 폴더 자동 생성

**main()**
- 명령줄 인자 파싱
- 캐릭터 및 포즈 데이터 로드
- 배치 생성 루프 실행
- 진행 상황 출력

#### 설정 상수

```python
API_URL = "http://localhost:7860/sdapi/v1/txt2img"
IMAGE_SIZE = (832, 1216)  # 가로 x 세로 (SDXL/Illustrious 네이티브)
STEPS = 28
CFG_SCALE = 7.5
WEBP_QUALITY = 95
SAMPLER = "DPM++ 2M"
SCHEDULER = "Karras"
```

#### 명령줄 인터페이스
```
python sd_batch_generator.py --character 프로젝트\캐릭터 --mode emotions --range 0-20
```

**인자:**
- `--character`: 프로젝트\캐릭터 형식 (필수)
- `--mode`: emotions, poses, h_scenes, scenes_otokonoko
- `--range`: 시작-끝 형식 (예: 0-20)

### 2. pose_database.json

#### 구조
```json
{
  "_schema": { ... },
  "emotions": { "00": "프롬프트", ... },
  "poses": { "21": "프롬프트", ... },
  "h_scenes": { "40": "프롬프트", ... },
  "scenes_otokonoko": { "140": "프롬프트", ... }
}
```

#### 섹션별 범위
- **emotions**: 00-20 (21개) - 감정 표현
- **poses**: 21-37 (17개) - 일반 포즈 및 상호작용
- **h_scenes**: 40-75 (36개) - 여성 캐릭터 H씬
- **scenes_otokonoko**: 140-170 (31개) - 오토코노코 캐릭터 H씬

#### 프롬프트 규칙
1. 첫 태그가 라벨로 사용됨
2. 가중치는 (태그:1.5) 형식
3. 검열 태그는 무광 검정 스타일로 통일
4. 가슴은 항상 검열되지 않음 (uncensored breasts:1.5)

#### 검열 표준
```
censored, (matte black censor:1.9), (painted black censorship:1.8), (solid black rubber censor:1.7)
```

### 3. 캐릭터 JSON

#### 필수 필드
```json
{
  "name": "캐릭터 이름",
  "checkpoint": "모델파일.safetensors",
  "vae": "vae파일.safetensors",
  "positive_prompt": "캐릭터 외형 프롬프트",
  "negative_prompt": "제외할 요소 프롬프트"
}
```

#### 프롬프트 구성 원칙

**positive_prompt:**
- 외형: 머리 스타일, 눈 색상, 체형
- 의상: 기본 복장
- 특징: 고유한 시각적 특징

**negative_prompt:**
- 품질 제외: worst quality, low quality, blurry
- 해부학적 문제: bad anatomy, bad hands, extra fingers
- 동물 특징: animal ears, cat ears, beast ears, fox ears, dog ears, animal tail
- 검열 오작동 방지: censored breasts, nipple censorship
- 캐릭터 타입별 제외 요소:
  - 여성: 1boy, male, masculine, beard
  - 오토코노코: 1girl, female, breasts, female genitalia
