# SD 이미지 에셋 제작 가이드

## 캐릭터 제작 프로세스

### 1단계: 캐릭터 컨셉 정의

#### 기본 정보 결정
- 캐릭터명 (영문 약어 권장)
- 성별/타입 (여성 / 오토코노코)
- 프로젝트 분류

#### 외형 설정
- **머리 스타일**: 길이, 색상, 형태
- **눈 색상 및 형태**
- **체형**: 신장, 체격, 가슴 크기 등
- **기본 의상**: 상의, 하의, 속옷
- **고유 특징**: 액세서리, 타투, 특이 사항

### 2단계: 캐릭터 JSON 작성

#### 파일 생성
경로: `projects\[프로젝트명]\characters\[캐릭터명].json`

#### JSON 구조
```json
{
  "name": "캐릭터영문명",
  "checkpoint": "모델파일명.safetensors",
  "vae": "vae파일명.safetensors",
  "positive_prompt": "...",
  "negative_prompt": "..."
}
```

### 3단계: 프롬프트 작성

#### Positive Prompt 구성 원칙 (신규 R8.1 규격: BREAK 분리)

구조:
```
[1. 공통 품질 티어] BREAK [2. 캐릭터 기본 축 및 외형]
```
- **공통 품질 티어**: `masterpiece, best quality, newest, absurdres, anime coloring, clean background, soft lighting BREAK`
- **조립 메커니즘**: `sd_batch_generator.py`가 포즈 DB의 [포즈/구도/표정]을 BREAK 앞단에 자동 배치하여, 카메라 앵글과 포즈가 긴 외형 묘사에 밀리지 않고 최고 우선순위로 적용됩니다.

**1. 캐릭터 타입 선언**
- 여성: `1girl, solo`
- 오토코노코: `1boy, solo, androgynous, (otokonoko, femboy:1.2), delicate feminine face, slender build, flat chest`

**2. 머리 스타일 (우선순위 높음)**
```
(hair_color hair_style:1.4), (specific_description:1.3)
```
예시:
- `(sky blue very long twin tails:1.4), (waist length twintails:1.3)`
- `(chest length magenta pink hair:1.4), (one eye covered by asymmetrical bangs:1.3)`
- `(very long crimson wine-red hair:1.4), (waist length flowing hair:1.3)`

**3. 얼굴 및 눈**
```
eye_color eyes, facial_features
```
예시: `golden eyes, sharp gaze, confident expression`

**4. 체형**
```
height, build, chest_size
```
예시:
- 여성: `tall, athletic build, large breasts, toned body`
- 오토코노코: `petite, slender build, flat chest, narrow shoulders`

**5. 기본 의상**
```
top, bottom, underwear
```
예시: `white shirt, black skirt, red bra, red panties`

**6. 액세서리 및 특징**
```
accessories, unique_features
```
예시: `hair ribbon, choker, mechanical arms`

#### Negative Prompt 구성 원칙

**1. 품질 제외 (필수)**
```
worst quality, low quality, blurry, bad anatomy, bad hands, extra fingers, extra limbs, deformed, disfigured, watermark, signature, text, jpeg artifacts, cropped
```

**2. 동물 특징 차단 (필수)**
```
animal ears, cat ears, beast ears, fox ears, dog ears, animal tail
```

**3. 성별/타입 차단**
- 여성 캐릭터:
```
1boy, male, masculine, beard, mustache, facial hair, muscular
```
- 오토코노코 캐릭터:
```
1girl, female, breasts, large breasts, heavy cleavage, female genitalia, female anatomy, muscular, manly, beard, mustache, facial hair, visible penis, large penis, erection, testicles
```

**4. 검열 오작동 방지 (필수)**
```
(censored breasts:1.6), (covered breasts:1.6), (censored chest:1.6), (black bar on breasts:1.5), (breast censorship:1.5), (nipple censorship:1.6), (censored nipples:1.6), upper body censored, torso censored
```

**5. 특정 색상 오염 방지 (필요시)**
머리색이 피부나 의상에 번지는 경우:
```
(hair_color liquid on skin:1.6), (hair_color paint on body:1.6), (hair_color color liquid:1.5)
```
예: `(red liquid on breasts:1.6), (red paint on chest:1.6), (wine color liquid:1.5)`

**6. 원치 않는 머리색 차단 (필요시)**
```
(unwanted_color hair:1.5), (unwanted_shade:1.4)
```
예: `(black hair:1.5), (dark hair:1.4), (red hair:1.5)`

**7. 특정 신체 부위 차단 (기계 신체 등)**
```
(body_part description:1.5)
```
예: `(mechanical legs:1.5), (robot legs:1.4), (metal feet:1.5)`

**8. H씬 및 감정 포즈 상충 태그 제외 (필수)**
```
sweat, perspiration, sweat drops, wet hair, liquid, splatter, stains, smudge
```
- 위 태그들은 H씬이나 땀, 눈물, 감정 묘사와 정면 충돌하여 포즈의 효과를 지워버리므로 네거티브에 절대 넣지 않습니다.

#### 프롬프트 작성 체크리스트

- [ ] 캐릭터 타입 명확히 지정
- [ ] 머리 스타일 상세히 서술 (높은 가중치)
- [ ] 원치 않는 머리색 차단
- [ ] 동물귀 차단
- [ ] 검열 오작동 방지
- [ ] 성별 반대 특징 차단
- [ ] H씬 상충 태그(sweat, liquid 등) 네거티브 제외 확인

### 4단계: 테스트 생성

#### 소규모 테스트
```bash
python sd_batch_generator.py --character 프로젝트\캐릭터 --mode emotions --range 0-5
```

#### 확인 사항
1. **머리 스타일**: 설명과 일치하는가?
2. **머리 색상**: 정확하고 오염 없는가?
3. **동물귀**: 나타나지 않는가?
4. **성별/타입**: 올바르게 표현되는가?
5. **검열**: 가슴은 검열되지 않았는가?

#### 문제별 해결 방법

**머리색 오염 문제:**
- Negative에 `(color liquid on skin:1.6)` 추가
- 예: 빨강→`(red liquid on breasts:1.6)`

**동물귀 나타남:**
- `animal ears, cat ears, beast ears, fox ears, dog ears, animal tail` 확인

**머리 스타일 불일치:**
- Positive에서 가중치 상향 `(description:1.5)`
- 더 구체적인 서술 추가

**성별 혼동:**
- Negative에 반대 성별 태그 강화
- 오토코노코의 경우 `flat chest` 강조

**여성기 나타남 (오토코노코):**
- `female genitalia, female anatomy` 추가

**남성기 나타남 (여성):**
- `visible penis, erection, testicles` 추가

### 5단계: 전체 생성

테스트 결과가 만족스러우면 전체 포즈 생성:

```bash
# 감정 표현 (0-20)
python sd_batch_generator.py --character 프로젝트\캐릭터 --mode emotions --range 0-20

# 일반 포즈 (21-37)

# H씬 - 여성 (40-75)
python sd_batch_generator.py --character 프로젝트\캐릭터 --mode h_scenes --range 40-75

# H씬 - 오토코노코 (140-170)
python sd_batch_generator.py --character 프로젝트\캐릭터 --mode scenes_otokonoko --range 140-170
```

## 포즈 데이터베이스 수정

### 언제 수정하는가?
- 새로운 감정/포즈 추가
- 기존 포즈 표현 개선
- 검열 스타일 변경
- 특정 요소 제거/추가

### 수정 절차

1. `pose_database.json` 열기
2. 해당 섹션 찾기
3. 프롬프트 수정
4. 첫 태그가 라벨임을 유지
5. 검열 스타일 일관성 유지

### 프롬프트 작성 원칙

**감정 표현 (emotions):**
- 표정, 자세, 시선, 손 위치 명확히
- 카메라 앵글: `cowboy shot`

**일반 포즈 (poses):**
- 인터랙션 대상 명시 (`faceless male`, `pov`)
- 신체 접촉 상세히 서술
- 의상 상태 명시

**H씬 (h_scenes, scenes_otokonoko):**
- 자세와 앵글 명확히
- 삽입 및 접촉 서술
- 검열 태그 항상 포함
- 가슴 검열 방지 태그 포함:
  ```
  topless, bare chest, (uncensored breasts:1.5), (visible nipples:1.4), (exposed breasts:1.3)
  ```
- 정액씬에 과다 분비 강조:
  ```
  (excessive cum:1.4), (huge cumshot:1.3), (cum overflowing:1.3)
  ```

### 검열 표준 (통일)
```
censored, (matte black censor:1.9), (painted black censorship:1.8), (solid black rubber censor:1.7)
```
- 모자이크나 바 형태가 아닌 무광 검정색
- 성기 부위만 검열
- 가슴은 항상 노출
