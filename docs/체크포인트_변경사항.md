## 핵심 기술 사양

### 1. e-Pred 채택의 의의

#### 표준 스케줄링 완벽 호환
- v-Pred와 달리 **표준 엡실론 예측(e-Pred)** 방식
- WebUI Forge 내부 샘플러 파라미터 **수동 변경 불필요**
- 기존 `sd_batch_generator.py`의 샘플러 우선순위 그대로 사용:
  - DPM++ 2M SDE Karras
  - DPM++ 2M Karras
  - DPM++ 2M
  - Euler a

#### 스케줄러 불일치 문제 원천 차단
- 회색 노이즈 현상 없음
- 픽셀 깨짐 현상 없음
- 페이로드 규격 100% 호환

## 5. 이전 버전과의 차이점

### 해상도 변경
| 항목 | 이전 (896×1280) | 현재 (832×1216) |
|------|-----------------|-----------------|
| 픽셀 수 | 1,146,880 | 1,011,712 |
| 종횡비 | 0.7:1 | 0.684:1 |
| 최적화 | 고해상도 우선 | 네이티브 해상도 |
| VRAM | 더 많이 사용 | 안정적 사용 |

### 장점
1. **네이티브 해상도**: SDXL/Illustrious 학습 해상도와 정확히 일치
2. **안정성 향상**: VRAM 사용량 감소, 안정적 생성
3. **품질 향상**: 네이티브 해상도에서 최적 성능 발휘
4. **속도 향상**: 픽셀 수 감소로 생성 속도 약간 증가

## 7. 실전 투입 가이드

### 즉시 사용 가능
스크립트나 API 코드 수정 없이:

```bash
# 1. WebUI에서 체크포인트 선택
# 2. 명령어 실행
python -u sd_batch_generator.py --char [약칭] -r [로스터]
```

### 예시 명령어

```bash
# 오토코노코 캐릭터 전체 생성
python -u sd_batch_generator.py --char mik -r oto

# 특정 포즈만 재생성 (검열 태그 수정본)
python -u sd_batch_generator.py --char mik -r oto --codes "41,42,44,45,46,50,54"

# 전체 캐릭터 일괄 생성
python -u sd_batch_generator.py --all-chars -r oto
```
