# [Step 1] 기본 정보 및 치환 변수 등록 명세

본 문서는 젠잇의 **[기본] 탭**과 **[에셋] 탭의 치환 변수 설정**에 그대로 복사·붙여넣기하여 사용하는 명세서입니다.

## 1. [기본] 탭 입력 항목

### 1.1 제목 (Title)
```text
[경영/하렘] 심야 메이드 카페 & 언더돌 육성기
```

### 1.2 한줄소개 (Short Description, 20자 이내)
```text
적자 메이드 카페를 최고 아이돌 무대로!
```

### 1.3 상세설명 (Description, 공략 힌트 포함)
```text
적자와 폐업 위기에 놓인 아키하바라 뒷골목의 지하 메이드 카페 '르 시엘(Le Ciel)'.
당신은 신임 점장 겸 프로듀서로 부임하여 개성 넘치는 메이드 4명을 이끌게 됩니다.
낮에는 메뉴 개발과 매장 인테리어를 확장하는 카페 경영 타이쿤을 즐기고, 밤에는 메이드들을 지하 아이돌로 훈련시켜 매일 밤 열광적인 무대 라이브와 체키회를 성공시키세요!

[💡 공략 가이드 & 관계 진전 힌트]
- Phase 1 (0~39%): 비즈니스 관계. 성실히 근무 지시를 내리고 피로를 케어해 주세요.
- Phase 2 (40~69%): 사적인 신뢰 형성. 개별 면담을 통해 메이드들의 숨겨진 고민과 결핍을 해결해 주세요.
- Phase 3 (70~89%): VIP 밀착 관계. 단둘이 백스테이지나 무대에서 비밀 특훈 및 스킨십이 해금됩니다.
- Phase 4 (90~100%): 전속 헌신. 점장만을 위한 심야 단독 공연 및 밀실 서비스가 해금됩니다.
* 쿨뷰티 바리스타 '시온'은 마음을 여는 데 +10%의 추가 호감도가 필요합니다.
```

### 1.4 태그 (Tags)
```text
메이드, 아이돌, 타이쿤, 경영, 하렘, 순애, 시뮬레이션, 멀티엔딩
```

## 2. [에셋] 탭 - 치환 변수 (Variables) 등록 테이블

젠잇 [에셋] 탭 하단의 **[변수 추가]** 버튼을 눌러 아래 9개 변수를 등록하십시오. (영문 시작, 15자 이내 준수)

| 변수 키 (Key) | 기본값 | 데이터 형태 | 변수 역할 및 연동 설명 |
| :--- | :---: | :---: | :--- |
| **`turn_count`** | `1` | 숫자 | 대화 누적 턴 카운터 (매 턴 +1씩 영구 누적) |
| **`loc_cur`** | `001` | 문자열 | 현재 위치 코드 (`001`:홀, `002`:카운터, `003`:대기실, `004`:무대, `005`:점장실) |
| **`cafe_rank`** | `1` | 숫자 | 매장 등급 (`1`:지하단칸방, `2`:네온살롱, `3`:아키바랜드마크) |
| **`gold`** | `150000` | 숫자 | 보유 운영 자금 (원 단위, 낮 영업/체키 판매로 획득, 설비 투자에 소모) |
| **`fans`** | `12` | 숫자 | 유닛 팬클럽 회원 수 (밤 라이브 성공 시 대폭 증가, 체키 매출 비례) |
| **`hana_str`** | `65` | 숫자 | 1번 메이드 '하나'의 피로/스트레스 수치 (0~100) |
| **`ruby_str`** | `50` | 숫자 | 2번 메이드 '루비'의 피로/스트레스 수치 (0~100) |
| **`sion_str`** | `40` | 숫자 | 3번 메이드 '시온'의 피로/스트레스 수치 (0~100) |
| **`yua_str`** | `55` | 숫자 | 4번 메이드 '유아'의 피로/스트레스 수치 (0~100) |

> **⚠️ 작성 주의사항**: 메시지나 프롬프트 본문에서 변수를 호출할 때는 반드시 **`{{gold}}원`**, **`{{fans}}명`**, **`{{cafe_rank}}단계`**와 같이 조사 분리 표기를 지켜주십시오.
