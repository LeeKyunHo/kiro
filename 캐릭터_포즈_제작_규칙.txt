================================================================================
  SD 배치 제너레이터 - 캐릭터 & 포즈 제작 규칙
================================================================================

이 문서는 sd_batch_generator.py에서 사용할 캐릭터 JSON과 pose_database.json
포즈 프롬프트를 작성하는 규칙을 정리한 것입니다.

외부 AI에게 캐릭터나 포즈를 만들어달라고 할 때 이 규칙을 제공하세요.

================================================================================
  1. 캐릭터 JSON 제작 규칙
================================================================================

위치: projects/{project_name}/characters/{prefix}.json

--------------------------------------------------------------------------------
1.1 필수 필드
--------------------------------------------------------------------------------

{
  "prefix": "jac",                    // 3-5글자 영문 소문자 (파일명 생성용)
  "default_mode": "otokonoko",        // "female" 또는 "otokonoko"
  "positive": "...",                  // 전체 프롬프트 (아래 규칙 참조)
  "negative": "...",                  // 네거티브 프롬프트 (아래 규칙 참조)
  "ref_weight": 0.7                   // IP-Adapter 강도 (0.5~0.8 권장)
}

--------------------------------------------------------------------------------
1.2 positive 프롬프트 작성 규칙
--------------------------------------------------------------------------------

**필수 태그 (앞에 위치):**
- masterpiece, best quality, highly detailed

- solo

4. 특이사항: (subtle bulge, tiny bulge under clothing:1.2) - 오토코노코만

- neutral calm expression

**주의사항:**

- 1girl/1boy 외에 성별 태그 없음 (포즈에서 처리)

--------------------------------------------------------------------------------
1.3 negative 프롬프트 작성 규칙
--------------------------------------------------------------------------------

**필수 품질 네거티브:**

extra limbs, deformed, disfigured, watermark, text

--------------------------------------------------------------------------------

"female":    emotions, poses, h_scenes 사용 (40-75번, 질 삽입)
"otokonoko": emotions, poses, scenes_otokonoko 사용 (140-170번, 항문 성교)

================================================================================
  2. 포즈 프롬프트 제작 규칙 (pose_database.json)
================================================================================

--------------------------------------------------------------------------------
2.1 기본 원칙
--------------------------------------------------------------------------------

1. **첫 태그 = 라벨**: 쉼표 앞의 첫 태그가 콘솔 출력 라벨이 됨
   ✅ "bashful blush, standing, red cheeks, ..."  → 라벨: bashful blush
   ❌ "standing, red cheeks, bashful blush, ..."  → 라벨: standing (구별 불가)

2. **성별 태그 금지**: 1girl, 1boy는 프로필에서 처리, 포즈에 넣지 말 것

3. **카메라 구도 명시**: cowboy shot, upper body, mid-shot, close-up 등

4. **코드 번호 규칙**:
   - 문자열로 작성: "00", "07", "145"
   - 정수로 해석되어 숫자 순서로 정렬됨
   - 결번 허용 (0, 5, 7, 42 이런 식도 가능)

--------------------------------------------------------------------------------
2.2 일상 포즈 작성 규칙 (emotions, poses)
--------------------------------------------------------------------------------

**감정 포즈 (00-19번):**

구조: [표정 라벨], [자세], [세부 묘사], [카메라]

예시:
"00": "neutral face, standing, looking at viewer, relaxed arms at sides, cowboy shot"
"07": "bashful blush, standing, red cheeks, averted gaze, hands clasped in front, cowboy shot"

**상호작용 포즈 (21-37번):**

필수 요소:
- pov (1인칭) 또는 third person (3인칭) 명시
- 남성 손/인물 묘사: large masculine hand, faceless male, nude male torso
- 접촉 부위: on cheek, groping breast, on waist
- 캐릭터 반응: flushed face, eyes closed, leaning into touch

예시:
"21": "cheek stroke, pov, standing, large masculine hand gently on cheek, eyes softly closed, leaning into hand, cowboy shot"

================================================================================
  3. 프로필 시스템 (pose_database.json → _profiles)
================================================================================

--------------------------------------------------------------------------------
3.1 프로필 종류
--------------------------------------------------------------------------------

female:          일반 여성 캐릭터
male:            남성 캐릭터
male_otokonoko:  오토코노코 (여성스러운 남성)

--------------------------------------------------------------------------------
3.2 프로필 vs 캐릭터 JSON positive
--------------------------------------------------------------------------------

**캐릭터 JSON에 positive가 있으면:**
→ 프로필의 base_positive 무시됨
→ profile 필드 불필요
→ 권장 방식 (유연성 높음)

**캐릭터 JSON에 char_prompt만 있으면:**
→ 프로필의 base_positive + char_prompt 조합
→ profile 필드 필수
→ 레거시 방식

--------------------------------------------------------------------------------
3.3 male_otokonoko 프로필 구조 예시
--------------------------------------------------------------------------------

"male_otokonoko": {
  "base_positive": "masterpiece, best quality, highly detailed, 
                    clean background, soft lighting, character portrait, 
                    cowboy shot, 1boy, solo, androgynous, feminine face, 
                    slender build, flat chest, delicate features",
  
  "base_negative": "worst quality, low quality, blurry, bad anatomy, bad hands, 
                    ..., 1girl, female, breasts, large breasts, female genitalia, 
                    female anatomy, uncensored, no censor, thin censorship, 
                    bar censor, line censor, mosaic, pixelated, 
                    censored breasts, covered breasts, visible penis, ..."
}

  5. 체크리스트
================================================================================

**캐릭터 JSON 제작 시:**
□ prefix 3-5글자 영문 소문자
□ default_mode: "otokonoko" (오토코노코인 경우)
□ positive: (1boy:1.3) 또는 (1girl:1.2) 포함
□ positive: (subtle bulge:1.2) 포함 (오토코노코만)
□ positive: cowboy shot 포함
□ negative: 반대 성별 강하게 방지 (1.4 가중치)
□ negative: (female genitalia:1.3) 포함 (오토코노코만)

**포즈 프롬프트 제작 시:**
□ 첫 태그가 구별되는 라벨
□ 성별 태그(1girl/1boy) 없음
□ H씬: anal penetration (오토코노코) / vaginal penetration (여성)
□ H씨: 검열 태그 6개 라인 포함
□ H씬: bare breasts, uncensored breasts 포함
□ 펠라(오토코노코): from side view, third person
□ 카메라 구도 명시 (cowboy shot, upper body 등)

**검열 확인:**
□ 하반신만: on genitals, on groin, lower body
□ 검은 박스: solid black, black box, pitch black
□ 가슴 노출: bare breasts, uncensored breasts
□ 네거티브: bar censor, mosaic, censored breasts 방지
