==============================================================================
  0. 이 도구는 무엇인가
==============================================================================

  로컬 Stable Diffusion WebUI에 명령을 보내서
  캐릭터 챗봇용 표정·포즈 이미지를 한 번에 여러 장 자동 생성하는 CLI 도구.

  생성이 끝나면
    - 이미지가 projects/{로스터}/assets/{캐릭터}/ 폴더에 저장되고
    - 윈도우 탐색기가 자동으로 열리고
    - 젠잇(Genit)에 붙여넣을 마크다운 호출 코드가 출력됩니다.

  핵심: JSON 파일에 항목을 늘리면 코드 수정 없이 생성 장수가 늘어납니다.


==============================================================================
  1. 폴더 구성
==============================================================================

  kiro\
   ├─ sd_batch_generator.py     실행 파일
   ├─ pose_database.json         프롬프트 DB (모든 로스터 공유)
   ├─ 사용법.txt                  이 문서
   ├─ 에파_기능명세.md             기능 명세 (AI용)
   ├─ PROJECT_GUIDE.md            기술 명세 (개발자/AI 에이전트용)
   │
   └─ projects\
       ├─ dark_generals\          흑막사천왕 로스터 (별칭: dar)
       │   ├─ characters\         캐릭터 JSON
       │   ├─ references\         IP-Adapter 참조 이미지
       │   └─ assets\             생성 결과 (git 제외)
       │       └─ {캐릭터}\{캐릭터}_{번호}.webp
       ├─ oto\                    오토코노코 로스터 (별칭: oto)
       ├─ school\                 학원물 로스터 (별칭: school)
       └─ fth\                    판타지 하렘 로스터 (별칭: fth)

  새 로스터 추가: projects\{이름}\characters\, references\, assets\ 폴더 만들면
  --roster {이름} 으로 자동 인식됩니다. 코드 수정 불필요.

==============================================================================
  3. WebUI 세팅 (최초 1회)
==============================================================================

  3-1. webui-user.bat 수정 (필수)

    set COMMANDLINE_ARGS=--api

    VRAM 8GB 권장 추가 옵션:
    set COMMANDLINE_ARGS=--api --medvram-sdxl --xformers

    ★ --xformers 와 --opt-sdp-attention 동시 사용 금지
    ★ 변경 후 콘솔 창 완전히 닫고 재실행해야 적용됨

  3-2. WebUI Settings 탭 (필수)

    Saving images/grids → Images filename pattern 완전히 비우기 → Apply
    (값이 남아있으면 [WinError 87] 에러 발생, 파일이 0KB로 저장됨)

  3-3. Forge 사용 시 권장값 (RTX 4060 Ti 8GB 기준)

    Diffusion with Low Bits  Auto
    Swap Method              Queue
    Swap Location            CPU
    Clip skip                2

  3-4. 모델 선택 — 놓치기 쉬움

    스크립트는 모델을 지정하지 않습니다.
    WebUI 좌측 상단 Stable Diffusion checkpoint에서 직접 선택하세요.

    해상도: 832×1216 고정 (SDXL/Illustrious/Pony 계열)
    SD1.5 쓰려면 sd_batch_generator.py에서 IMAGE_SIZE = (512, 768)로 수정


==============================================================================
  4. 캐릭터 JSON 추가 방법
==============================================================================

  projects\{로스터}\characters\{이름}.json 파일 생성.

  최소 형식 (positive 방식 — 권장):

    {
      "prefix": "mika",
      "default_mode": "female",
      "positive": "masterpiece, best quality, ..., 1girl, solo, silver hair, blue eyes, ...",
      "negative": "1boy, male, child, loli, uncensored, no censor, thin censorship",
      "ref_weight": 0.7
    }

  레거시 형식 (char_prompt 방식):

    {
      "prefix": "mika",
      "profile": "female",
      "default_mode": "female",
      "char_prompt": "silver hair, blue eyes, school uniform",
      "custom_neg": "glasses"
    }

  default_mode 값:
    "female"     → emotions, poses, h_scenes (00-20, 21-39, 40-75)
    "otokonoko"  → emotions, poses, scenes_otokonoko (00-20, 21-39, 140-170)


==============================================================================
  5. pose_database.json 편집
==============================================================================

  이 파일이 도구의 심장. 여기에 적은 만큼 이미지가 나옵니다.

  ★ 첫 태그가 이름표가 됩니다 (가장 중요)

    [나쁜 예]  "00": "standing, front view, neutral expression"  → 라벨: standing
    [좋은 예]  "00": "neutral expression, standing, front view"  → 라벨: neutral expression

  ★ 포즈에 성별 태그(1girl/1boy) 넣지 마세요. 프로필 축에서 처리합니다.

  편집 후 항상 검사:
    python sd_batch_generator.py --test


==============================================================================
  6. 참조 이미지 (IP-Adapter) — 캐릭터 일관성
==============================================================================

  projects\{로스터}\references\{prefix}.webp 에 이미지를 넣으면 자동 적용됩니다.
  없어도 됩니다 (경고만 출력하고 텍스트만으로 생성).

  강도 조절:
    ref_weight: 0.5~0.8  실무 범위 (기본 0.7)
    1.0 이상             포즈까지 참조에 고정됨 (권장 안 함)

  부트스트랩 워크플로우 (자체 생성물 참조):
    1. python -u sd_batch_generator.py --char mika -r school --codes "0"
    2. Copy-Item "projects\school\assets\mika\mika_000.webp" "projects\school\references\mika.webp"
    3. (나머지 생성 — 참조 자동 적용)

==============================================================================
  8. 문제 해결
==============================================================================

  증상                            원인 / 대응
  ----------------------------    ------------------------------------------
  WebUI 연결 불가                  --api 누락, WebUI 콘솔 종료
  파일이 0KB / [WinError 87]       Images filename pattern 비우고 Apply
  전부 건너뜀                      이미 파일 존재. 삭제 후 재실행
  출력이 중간에 잘림                python -u 옵션 추가
  SyntaxError (한글 입력됨)         에디터 포커스 문제. 파일 직접 수정 시
                                   에디터 본문 클릭 후 입력
  BOM 오류 (JSON 파싱 실패)         메모장으로 저장 시 발생. Python으로 저장하거나
                                   PowerShell: [System.IO.File]::WriteAllText(
                                     $path, $content,
                                     [System.Text.UTF8Encoding]::new($false))
  남캐인데 여성으로 나옴             profile 설정 확인
  화풍이 예상과 다름                WebUI 체크포인트 확인 (스크립트는 모델 미지정)
