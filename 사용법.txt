  1. 가장 많이 쓰는 명령어 (치트시트)
==============================================================================

  ★ 주의: 터미널 출력 잘림을 방지하기 위해 항상 `python -u` 로 실행하세요.

  ── [원클릭] 작품 전체 캐릭터 생성 (감정+배경+포즈+H씬+이벤트 전부) ──
  python -u sd_batch_generator.py --all-chars -r sea        # 바다/비치 바
  python -u sd_batch_generator.py --all-chars -r dar        # 흑막사천왕
  python -u sd_batch_generator.py --all-chars -r oto        # 오토코노코
  python -u sd_batch_generator.py --all-chars -r school     # 학원물

  ── 단일 캐릭터 생성 ───────────────────────────────────────────────────────
  python -u sd_batch_generator.py --char ren -r sea          # 렌 전체 에셋 생성
  python -u sd_batch_generator.py --char rog -r dar          # 로그 전체 에셋 생성

  ── 특정 번호만 골라서 생성 ───────────────────────────────────────────────
  python -u sd_batch_generator.py --char ren -r sea --codes "0,1,2,3"   # 감정만
  python -u sd_batch_generator.py --char ren -r sea --codes "201-204"   # 메인 이벤트만
  python -u sd_batch_generator.py --char ren -r sea --codes "140-170"   # H씬만

  ── 배경 분위기 변경 (감정 씬 00~20 대상) ──────────────────────────────────
  python -u sd_batch_generator.py --char ren -r sea --bg-preset night
  python -u sd_batch_generator.py --char ren -r sea --bg "sunset beach bar background"

  ── 특정 파일 1개만 다시 만들기 (재생성) ──────────────────────────────────
  # 1. 다시 만들고 싶은 webp 파일을 삭제합니다:
  Remove-Item "projects\sea\assets\ren\ren_000.webp"
  # 2. 해당 번호를 실행하면 삭제된 파일만 새로 생성됩니다:
  python -u sd_batch_generator.py --char ren -r sea --codes "0"

  ── 실행 전 미리보기 (WebUI 없이 계획만 확인) ─────────────────────────────
  python sd_batch_generator.py --char ren -r sea --dry-run

  ── 파이프라인 정상 동작 자체 점검 ─────────────────────────────────────────
  python sd_batch_generator.py --test

  2. 주요 로스터 (작품 프로젝트) 안내
==============================================================================

  로스터는 `projects/` 폴더 안의 개별 작품입니다.
  작품에 `events.json`이 있으면 이벤트 씬(200번대)까지 한 번에 자동 생성됩니다!

  | 별칭    | 폴더 위치                  | 작품 설명 및 특징                         |
  |---------|----------------------------|--------------------------------------------|
  | `sea`   | `projects/sea/`            | 바다/비치 바 (배경 치환 + 이벤트 씬 완비)  |
  | `dar`   | `projects/dark_generals/`  | 흑막사천왕                                 |
  | `oto`   | `projects/oto/`            | 오토코노코 전문                            |
  | `school`| `projects/school/`         | 학원물                                     |
  | `fth`   | `projects/fth/`            | 판타지 하렘                                |

  * 신규 작품 추가: `projects/{원하는이름}/` 폴더를 만들고 그 안에 `characters/`를
    넣으면 `--roster {원하는이름}`으로 코드 수정 없이 즉시 작동합니다.

  3. 최초 1회 설치 및 WebUI 필수 세팅
==============================================================================

  3-1. 파이썬 및 필수 패키지 설치
    - Python 3.10 이상 설치
    - 패키지 설치: `pip install requests pillow`
    - 테스트: `python sd_batch_generator.py --test` (48 PASS 확인)

  3-2. SD WebUI 필수 세팅 (매우 중요 ★)
    1) WebUI 실행 bat 파일에 `--api` 추가:
       `set COMMANDLINE_ARGS=--api --medvram-sdxl --xformers`
    2) WebUI 웹 화면 > [Settings] > [Saving images/grids]:
       `Images filename pattern` 칸을 **완전히 빈칸**으로 비우고 [Apply settings] 클릭!
       (여기에 값이 들어있으면 에셋이 0KB로 저장되거나 에러가 납니다)
    3) 체크포인트 모델 선택:
       WebUI 좌측 상단에서 `Unholy Desire Mix Crimson v5.0` (또는 원하는 모델)을
       직접 선택해 두어야 합니다. (스크립트는 모델을 강제로 바꾸지 않습니다)


==============================================================================
  4. 배경 시스템과 이벤트 씬 활용법
==============================================================================

  4-1. 감정 씬(00~20) 배경 자동 치환
    - 기본 상태에서 감정 씬은 단색 배경(`clean background`)이지만,
      `projects/{roster}/background.json`이 있으면 작품 분위기 배경으로 자동 변경됩니다.
    - 예: `sea` 로스터는 감정 씬이 자동으로 "트로피컬 비치 바 테라스"로 생성됩니다.
    - 밤 분위기로 바꾸고 싶다면: `--bg-preset night`
    - 일회성 배경을 주고 싶다면: `--bg "rainy cafe background"`
    ★ 침대/욕실/벽 등 고유 장소가 있는 포즈나 H씬은 배경이 절대 섞이지 않습니다.

  4-2. 이벤트 씬(200번대) 자동 포함
    - `projects/{roster}/events.json`에 정의된 메인/랜덤 이벤트는
      `--all-chars`나 단일 캐릭터 실행 시 자동으로 감지되어 함께 출력됩니다.


==============================================================================
  5. 참조 이미지(IP-Adapter)로 캐릭터 일관성 유지하기
==============================================================================

  캐릭터 얼굴/체형을 완벽히 유지하고 싶다면:
  1. 먼저 0번(기본 표정)을 1장 생성합니다:
     `python -u sd_batch_generator.py --char ren -r sea --codes "0"`
  2. 마음에 드는 결과물을 `projects/sea/references/ren.webp` 로 복사합니다.
  3. 이제 전체 생성을 돌리면 ControlNet IP-Adapter가 자동으로 활성화되어
     모든 포즈와 씬에서 동일한 얼굴과 외형으로 생성됩니다!


==============================================================================
  6. 젠잇(Genit)에 에셋 등록하기
==============================================================================

  생성이 끝나면 터미널 맨 아래에 `젠잇(ZenIt) 복사용 에셋 블록`이 자동 출력됩니다.
  동시에 결과물이 저장된 윈도우 탐색기 폴더가 자동으로 열립니다.

  터미널에 출력된 아래 3가지를 복사해서 젠잇 봇 제작창에 붙여넣으세요:
  1) `이미지 호출 코드`: {{url}}ren/ren_000.webp
  2) `상태 매핑 가이드`: 어떤 감정/포즈가 몇 번 파일인지 목록
  3) `상태창 템플릿`: 챗봇 메시지에 붙여넣을 템플릿 문구


==============================================================================
  7. 문제 해결 (FAQ & Troubleshooting)
==============================================================================

  Q. "WebUI 연결 불가" 오류가 납니다.
  A. SD WebUI가 실행 중인지 확인하고, `webui-user.bat`에 `--api` 옵션이 들어가
     있는지 확인하세요. 주소는 `http://127.0.0.1:7860` 이어야 합니다.

  Q. 이미지가 0KB이거나 파일 생성 오류가 발생합니다.
  A. WebUI [Settings] -> [Saving images/grids] -> `Images filename pattern` 칸이
     비어있는지 확인하세요. 빈칸으로 만들고 [Apply settings]를 눌러야 합니다.

  Q. 실행했는데 "이미 존재 (건너뜀)" 라면서 전부 스킵됩니다.
  A. 에파는 이미 성공적으로 만든 파일은 다시 만들지 않습니다.
     다시 만들고 싶다면 해당 `.webp` 파일을 삭제하고 다시 실행하세요.

  Q. 파워셸 터미널에서 생성이 멈춘 것처럼 보입니다.
  A. 파이썬 버퍼링 때문일 수 있습니다. 명령어에 반드시 `-u` 플래그를 붙여서
     `python -u sd_batch_generator.py ...` 형태로 실행하세요.

  Q. 캐릭터를 새로 등록하고 싶어요.
  A. `projects/{roster}/characters/` 폴더에 `{캐릭터약칭}.json` 파일을 만드세요.
     상세한 태그 작성 요령은 `캐릭터_포즈_제작_규칙.txt`를 참고하세요.
